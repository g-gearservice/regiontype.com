# PLAN-pass.md

> 일이 시작될 때 만들고, 마일스톤마다 고친다. 끝에 한 번 쓰는 문서가 아니다.
> 검사는 `?rt=1` · `node relay/test.mjs` 둘뿐이다. 러너를 새로 세우지 않는다.

## 할 일

랭크 시즌(6개월)을 바로 세우고, 그 안에 3개월짜리 **리전 패스**(100레벨, 꾸미기 보상) 둘을 돌린다.

## 까닭

지금은 시즌이 끝나도 남는 게 없고, 판을 쌓을 까닭이 레이팅 하나뿐이다. 패스가 "오늘 한 판 더"의
까닭이 되고, 봇 꾸미기가 그 보상이 된다. 끝난 모습: 홈에 패스 레벨 띠, 판이 끝나면 XP가 오르고,
레벨마다 받은 꾸미기를 내 스타일 → 봇 스타일 탭에서 입힌다.

## 방법

### 시계

```
빅 시즌 (seasons, 6개월, reset=soft)  ── 레이팅·티어가 여기 묶인다
 ├─ 패스 1 (passes, 3개월, 100레벨)
 └─ 패스 2 (passes, 3개월, 100레벨)
```

`seasons` 는 그대로 쓰고 줄만 6개월로 넣는다. 패스는 `passes` 표를 따로 둔다 — 패스는
레이팅을 건드리지 않으므로 시즌과 섞지 않는다. 둘 다 사람이 줄을 넣고, 지금 시각을 덮는 줄이 없으면 닫힌다.

### 랭크 기준 (지금 있는 것 + 메울 것)

있음: Glicko-2, 표시 = r − 2·RD, 배치 5판, 리~특별시 × III·II·I (600부터 100씩), soft 리셋, 소급 승리.

메울 것:
- **시즌 결과 찍기** — 시즌이 끝날 때 `season_results(who, season_id, dev, final_tier, peak_tier, games)`.
  계정 화면에 "시즌 1 · 구 II". 최고 티어 배지는 영구 꾸미기로 준다.
- **최고 티어 기록** — `player_ratings.peak` 한 칸. 판마다 max 로 올린다.
- **특별시 위** — 특별시 I 안에서도 순위표 상위 N명 표시는 지금 순위표로 충분하다. 따로 티어를 더하지 않는다.
- **티어 강등 보호**는 하지 않는다 — Glicko가 이미 RD로 흔들림을 누른다.

### 패스

- **XP 원천** — 끝낸 판만(중도 이탈·플래그 판 제외). 판당 기본 + 점령 칸 수 비례, 랭크전 가산.
  하루 상한을 둬서 봇 농사를 막는다. 셈은 **서버(중계기)** 가 판 기록에서 낸다 — 브라우저가 보낸 XP는 믿지 않는다.
- **레벨** — 100레벨, 레벨당 고정 XP(곡선 없음: 계산·설명이 쉽다). 3개월에 평범하게 놀면 닿게 잡는다.
- **보상** — 꾸미기만. 레이팅·판 수 혜택 없음. 레벨마다 다 주지 않고 5레벨마다 큰 것, 사이는 작은 것(색·표정 변형).
- **보상 표** — `data/pass-<id>.json` (레벨 → 아이템 id). 패스마다 한 장.
- **받은 것** — `inventory(who, item, got_at)`. 패스가 끝나도 받은 건 남는다.

### 봇 에셋 — 잘 씌우는 틀

지금 봇 모습은 shape·expression·colour 셋이고, 호박 꼭지(`STEM_D`)가 '덧붙이는 조각'의 유일한 선례다.
그걸 일반화한다:

- **슬롯**: `hat`(머리 위) · `face`(눈 위·안경 등) · `back`(몸 뒤·날개·후광) · `trail`(판 중 자국) · 이름표 테두리.
- **좌표**: engine 의 `DEMI_VIEWBOX` 공간. 모양마다 키가 다르므로 **모양별 닻(anchor)** 표를 만든다 —
  각 SHAPE 의 radii 에서 −90°(정수리)·0°/180°(옆) 반지름을 읽어 `{ top, left, right }` 를 낸다. 손으로 적지 않고
  radii 에서 계산한다(새 모양이 생겨도 저절로 맞는다). 모자는 `top` 에 붙는다.
- **에셋 형식**: SVG path 문자열 + 채움(고정색 또는 `currentColor` = 몸 색). 파일 하나: `assets/bloub/items.js`
  (`{ id, slot, d, fill, scale }` 배열). `asset()` 를 태워 `?v=`.
- **그리기**: buddy.js 의 body 그룹에 슬롯별 `<g>` 를 두고(꼭지 자리처럼), back 은 paper 앞에 끼운다.
  `prefers-reduced-motion` 이면 흔들림·trail 을 끈다.
- **저장**: profile.face 를 `shape,expression,colour` 에서 `shape,expression,colour,hat,face,back` 로 늘린다
  (뒤에 붙이므로 옛 값도 읽힌다). 서버는 inventory 에 없는 아이템을 face 에 못 넣게 막는다.
- **봇 AI 말 모습** — `BOT_LOOK` 은 바꾸지 않는다(무료 모습만). 패스 아이템은 사람이 고른다.

## 위험

- 아이템이 모양마다 안 맞음 — 닻을 radii 에서 계산해 막는다. 그래도 `etoile`·`eclat` 처럼 뾰족한 건 모자별 보정 칸(`dy`)이 필요할 수 있다.
- XP 농사(봇전 반복) — 하루 상한 + 플래그 판 제외.
- profile.face 늘리기 — 옛 브라우저 거울(`rt.character`)이 새 칸을 모른다. 없으면 빈 슬롯으로 읽게.
- 100레벨 보상을 다 그리는 품. 5레벨마다 큰 것 20개 + 사이 변형으로 줄인다.
