# PLAN-license-tiers.md

> 라이선스 F~S 등급 → 직업 이름 5단계 계획서
> 검사는 `?rt=1` · `node relay/test.mjs` 둘뿐이다. 러너를 새로 세우지 않는다.

## 할 일

한 번 치고 F~A 등급을 받던 시험을, 카트라이더처럼 단계마다 따로 응시하는 라이선스 5개로 바꾼다.

## 까닭

등급이 타수 한 줄로만 갈렸다. 단계마다 시험 자체가 달라야 하고(코스·시간·조건), 위로 갈수록 어려워야 한다.

## 방법

등급표 (아래 → 위, 아래를 따야 위가 열린다. 경쟁전·일반전 따로):

| id | 이름 | 코스 | 시간 | 합격 조건 |
|---|---|---|---|---|
| `gamer` | 프로게이머 | 고른 코스 | 120초 | 완주 · 400타 · 정확도 93% · 오타 5 |
| `reporter` | 기자 | 고른 코스 | 120초 | 완주 · 600타 · 정확도 98% · 오타 1 |
| `basic` | 초급 | 전국 시군구에서 270자 무작위 | 60초 | 완주 · 정확도 90% |
| `mid` | 중급 | 〃 300자 | 60초 | 완주 · 정확도 90% |
| `expert` | 숙련 | 〃 320자 | 60초 | 완주 · 정확도 90% |

- 초급~숙련: 대한상공회의소 한글속기 3·2·1급의 1분당 요구 자수(270·300·320). 60초 안에 완주 = 그 자수를 낸 것.
  지명 평균 2.9타/자 → 실제 약 790·875·935타.
- 코스는 `/license/start` 가 `relay/pool.mjs` 에서 뽑아 이름 목록으로 내준다. 자수 합은 정확히 목표. 볼 때마다 다르다.
  클라는 그 이름만 `kr-sgg` 지도 위에서 가까운 순으로 이어 친다. 약칭은 끈다(자수가 전체 이름 기준이므로).
- 서버 저장: `license(who, mode, slug)` 그대로, `grade` 에 등급 id. 초급~숙련은 slug `kr-sgg`.
  잠금 = 같은 mode 에서 바로 아래 등급 이상을 가진 행이 있는가.
- 옛 A~F·S 기록은 `license_v1`·`license_s_v1` 로 옮겨 둔다(지우지 않음).

## 열린 물음

- [ ] 프로게이머·기자의 정확도·오타 기준 — 옛 C·A 줄을 그대로 옮김. 따로 정할까
- [ ] '타수만 보는 게 아니라' — 지금은 코스 종류·시간·정확도가 단계마다 다르다. 카트의 드리프트처럼 단계별 '기술'(띄어쓰기 이름, 긴 이름…)을 넣을까
- [ ] 초급~숙련은 한국어 화면 전용(속기 자수가 한글 기준)
- [ ] 같은 이름(중구·동구·강서구…)은 지도에서 '부산 중구'처럼 시도를 붙이고, 띄어쓰기가 든 이름은 뽑기에서 뺀다
- [ ] 정확도·타수는 지금처럼 클라가 보낸 값을 믿는다(서버는 hits·시간·잠금만 확인)
