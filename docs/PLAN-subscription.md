# PLAN-subscription.md

> 구독 세 단계 — Capital · Nation · World
> 검사는 `?rt=1` · `node relay/test.mjs` 둘뿐이다. 러너를 새로 세우지 않는다.

## 할 일

지도 범위와 봇 기능을 세 단계 구독(Capital 무료 · Nation · World)으로 나누고, 계정에 단계를 적어 화면과 중계기가 같은 단계를 본다.

## 까닭

3.0.0 에서 나라 고르기를 배포로 풀었다. 지금은 누구나 모든 나라의 **수도**를 친다 — 그게 Capital 이고 무료다.
그 위로 나라 전국(Nation)과 세계 비트맵(World)을, 봇 기능(어시스턴트·제너레이터·보이스오버)과 묶어 판다.

끝난 모습:

| 단계 | 지도 | 어시스턴트 | 제너레이터 | 보이스오버 |
|---|---|---|---|---|
| **Capital** (무료) | 모든 나라의 수도만. 나라 고르기 제한 없음 | 기본 | — | — |
| **Nation** | 모든 나라의 전국 구획(`<iso>-admin` + 그 아래). 나라 이동 제한 없음 | 프로 | 횟수 제한 | 무료급 — 봇이 말한다 |
| **World** | 세계 비트맵(`world-*`, 나라 단위)을 자유롭게 | 맥스 | 프로 | 프로 — 봇과 자율 대화 |

## 방법

- **단계는 서버에만 있다.** `user.plan`(`'capital' | 'nation' | 'world'`, 기본 `'capital'`)을 D1 에 적고 `/auth/me` 가 읽어 준다.
  브라우저는 `RT_PLAN` 으로 받아 *보여 주기만* 한다 — 막는 곳은 중계기다(경쟁전 판 배정·봇 호출·제너레이터).
  `RT_PIN` 과 같은 길: `auth.js` 의 `setPin` 옆에 `setPlan`, `rt-plan` 이벤트.
- **지도 범위**: `relay/plans.mjs`(`tools/build_plans.py` 생성물)를 단계별 코스 목록으로 넓힌다 —
  `capital` = 모든 `*-capital*` + 서울 동, `nation` = capital + 모든 `<iso>-admin` 갈래, `world` = nation + 세계 비트맵.
  `app.js` 는 `homeSlug()` 가 고르는 뿌리만 단계를 보고 바꾼다(Capital 은 수도, Nation 은 `<iso>-admin`).
- **봇 단계**: 지금 봇 대화(`/bot`, worker.mjs `botAsk`, `NV_KEY`)는 한 모델·한 한도다. 단계마다 모델·한도(`RL_BT`)를
  나누는 표를 worker 에 하나 둔다. 제너레이터·보이스오버는 아직 없는 기능 — 각자 마일스톤으로 떼어 낸다.
- **결제**는 별도 결정(열린 물음). 결제 전에는 개발 계정에서 `plan` 을 손으로 올려 시험한다.

## 열린 물음

- [ ] 결제 수단 — Stripe·Paddle·앱스토어 중 무엇. 값은 얼마. 월/연
- [ ] **제너레이터**가 무엇을 만드나 — 코스? 봇 모양? 문장? '제한'은 하루 몇 번
- [ ] **보이스오버** TTS 를 어디서 — 브라우저 `speechSynthesis`(무료·말마다 목소리 다름) 또는 유료 TTS(키는 Worker 안에만)
- [ ] 어시스턴트 기본·프로·맥스가 모델 차이인지, 한도 차이인지, 둘 다인지
- [ ] Nation 의 '전국' 은 admin-1 만인가, 그 아래(시군구급)까지인가 — 한국은 이미 시군구가 있다
- [ ] 계정 나라(`pin_country`)는 단계와 상관있나 — 지금은 '고른 나라가 없을 때의 기본값' 일 뿐이다
- [ ] 로그인 안 한 사람은 Capital 로 보나

## 위험

- 단계 검사를 브라우저에만 두면 누구나 콘솔로 푼다 — 막는 곳은 반드시 중계기.
- 봇·TTS 는 돈이 드는 외부 호출이다 — 단계별 한도가 먼저 있어야 무료 단계가 지갑을 뚫지 않는다.
- 세계 비트맵 데이터는 아직 없다 — `tools/build_world.py` 가 나라 단위 판을 새로 찍어야 한다.
