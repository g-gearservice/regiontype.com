개발

정적 파일뿐이다.

빌드 단계도, 패키지 매니저도, 프레임워크도 없습니다. 지도는 도구가 찍고, 판정은 함수 하나가 맡고, 검사는 둘뿐입니다.

  1. 01

    지명을 찍습니다

    행정구역 경계와 이름은 도구가 지도·코스 데이터로 찍습니다. 데이터를 손으로 고치지 않고 도구를 고칩니다.

    데이터 · tools/*.py
  2. 02

    읽기를 붙입니다

    화면 말이 한국어가 아니면 그 말의 이름을 '열쇠'로 접어 견줍니다. 일본어는 히라가나, 중국어는 병음.

    데이터 · kr-read
  3. 03

    판정합니다

    핵심은 matchInput() 하나. 약칭은 그 약칭으로 이어질 미점령 항목이 자기 자신뿐일 때만 확정됩니다.

    엔진 · app.js
  4. 04

    그립니다

    화면은 app.js 와 style.css 두 장. 색·간격은 맨 위 커스텀 프로퍼티에서 땁니다.

    화면 · style.css
  5. 05

    검사합니다

    판정 엔진 자체검사 ?rt=1 과 중계기 검사 relay/test.mjs. 검사는 이 둘뿐입니다.

    검사 · ?rt=1
  6. 06

    내보냅니다

    릴리스마다 static-A.B.C 브랜치에서 일하고, main 에 머지하면 GitHub Pages 로 나갑니다.

    배포 · main

스토리

남는 쪽은
손이었습니다.

  1. 01

    읽어서는 이름이 남지 않았습니다.

    지도에서 구 이름을 눈으로 따라가도 자리와 철자가 따로 놀았습니다. 남는 쪽은 손이었습니다.

  2. 02

    타자의 방식을 지명에 가져왔습니다.

    다음 글자를 치려면 이름을 통째로 붙들고 있어야 합니다. 설치 없이, 가입하지 않아도 지도에서 고르고 칩니다.

  3. 03

    처음 길은 서울 한 바퀴였습니다.

    무작위 목록은 지리가 아닙니다. 서쪽 끝 강서구에서 이웃한 구를 따라 시계 방향으로 성북구까지 잇습니다. 구 안의 동도 같은 방식으로 이웃을 따라갑니다.

  4. 04

    사람이 드나드는 동을 골랐습니다.

    법정동은 땅에 붙은 이름이고, 행정동은 동주민센터 하나가 맡는 구역입니다. 플레이하는 423곳은 행정동입니다. 설정에서는 법정동으로 바꿔 칠 수도 있습니다.

  5. 05

    한 줄 소개는 자료에 있는 것만 올립니다.
