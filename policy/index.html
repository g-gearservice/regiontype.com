개인정보처리방침

2026년 9월 18일 시행

regiontype은 지명 타자연습입니다. 게임 자체는 로그인 없이 그대로 돌고, 아래 값들은 순위표에 이름을 올리기로 한 사람에게만 생깁니다.

안 받는 것

비밀번호를 받지 않습니다. 회원가입 메일도, 실명도 받지 않습니다. 광고나 방문자 분석 스크립트를 넣지 않고, 쿠키도 쓰지 않습니다.

로그인 (Google·Apple)

로그인은 Google 또는 Apple 계정으로 합니다. Google에는 openid 범위만 요청하고, Apple에는 아무 범위도 요청하지 않습니다 — 그래서 메일도 이름도 넘어오지 않습니다. 공급자가 주는 것은 그 계정을 가리키는 번호(sub)뿐이고, 이 값은 저장하기 전에 저희 서버 키로 한 번 더 섞어(HMAC) 저장합니다. 원래 번호는 어디에도 남지 않습니다.

패스키 (2단계 인증)

패스키는 선택입니다 — 계정에 하나라도 걸어 두면 다음 로그인부터 그 기기의 지문·얼굴·PIN으로 한 번 더 확인합니다. 저장하는 값은 기기가 만든 공개키와 자격증명 번호뿐이고, 지문이나 얼굴 자체는 기기 밖으로 나오지 않습니다.

복구 코드

패스키를 켜면 일회용 복구 코드 8개를 한 번만 보여줍니다. 저장은 그 코드의 해시값만 하고, 코드 원문은 서버에 남지 않습니다. 코드를 쓰면 그 줄은 지워집니다.

로그인 세션

로그인 상태는 쿠키가 아니라 브라우저의 localStorage에 담긴 토큰으로 유지합니다. 이 토큰에는 임의로 만든 계정 번호와 만료 시각만 들어 있고, 90일 뒤 만료됩니다.

순위표

순위표에 이름을 올리면 코스·제한 시간·고른 이름·점수·정확도·시각이 공개로 걸립니다. 줄의 주인은 화면에 보이는 이름이 아니라 브라우저가 한 번 만든 난수라, 같은 이름을 다른 사람이 써도 서로의 기록에 손댈 수 없습니다. 결과 화면의 '내 기록 내리기'로 언제든 자기 줄을 지울 수 있습니다.

피드백

피드백은 GitHub 공개 이슈로 그대로 올라갑니다. 회신 주소는 받지 않습니다 — 입력칸 자체가 없습니다. 보낸 내용과 함께 종류, 앱 버전, 보고 있던 페이지 주소, 브라우저 정보가 같이 올라갑니다. 이 내용은 누구나 볼 수 있으니, 남길 내용에 개인 정보를 적지 마세요.

어디에 저장되나

순위표·계정·패스키 값은 Cloudflare D1(아시아·태평양 리전)에 저장합니다. 피드백은 GitHub 저장소의 공개 이슈로 저장합니다. 그 밖에 저희가 따로 두는 서버나 데이터베이스는 없습니다.

지우고 싶을 때

순위표 줄은 위에 적은 대로 스스로 지울 수 있습니다. 계정 전체를 지우는 화면은 아직 없습니다 — 기기와 복구 코드를 모두 잃어 로그인할 방법이 없다면 피드백으로 코스·제한 시간·이름을 적어 보내 주세요. 위에 적은 대로 그 내용도 공개 이슈로 열립니다.

제3자

이 서비스가 실제로 주고받는 곳은 로그인을 처리하는 Google·Apple, 피드백이 올라가는 GitHub, 그리고 사이트와 로그인 서버를 올려 두는 Cloudflare뿐입니다. 그 밖의 광고·분석·추적 서비스는 쓰지 않습니다.

바뀔 수 있습니다

기능이 바뀌면 이 문서도 같이 고칩니다. 맨 위의 시행일로 마지막으로 고친 날을 알 수 있습니다.

Privacy Policy

Effective September 18, 2026

regiontype is a place-name typing drill. The game itself works without signing in. Everything below only applies once you choose to sign in and post to the leaderboard.

What we don't collect

No passwords. No signup email, no real name. No ads, no analytics scripts, no cookies.

Signing in (Google · Apple)

Sign-in goes through Google or Apple. We request only the openid scope from Google and no scope at all from Apple — so neither hands us an email or a name. The only thing the provider gives us is a number identifying that account (its sub), and we HMAC-hash it with a server-side key before storing it. The original number is never kept anywhere.

Passkeys (second step)

A passkey is optional. Once you register one, the next sign-in also asks for that device's fingerprint, face, or PIN. We store only the public key and credential id the device hands us — the biometric itself never leaves your device.

Recovery codes

Turning on a passkey shows eight one-time recovery codes, once. We store only their hash, never the codes themselves. Using a code deletes that entry.

Sessions

Sign-in state lives in a token in your browser's localStorage, not a cookie. The token holds nothing but a random account id and an expiry, and it expires after 90 days.

Leaderboard

Posting a score publishes the course, time limit, the name you chose, your score, accuracy, and a timestamp. Each row is owned by a random id the browser generates once, not by the display name, so two people can share a name without touching each other's rows. "Remove my score" on the result screen deletes your own rows at any time.

Feedback

Feedback is posted as-is to a public GitHub issue. We don't collect a reply address — there is no field for one. Your message goes up alongside its category, the app version, the page URL you were on, and your browser's user agent. Anyone can read this, so don't put personal information in what you send.

Where it's stored

Leaderboard, account, and passkey data live in Cloudflare D1 (Asia-Pacific region). Feedback lives as public issues in our GitHub repository. We keep no other server or database.

Deleting things

You can remove your own leaderboard rows yourself, as above. There is no self-service full account deletion yet — if you've lost both your device and your recovery codes, write the course, time limit, and name in feedback and send it. As above, that also opens as a public issue.

Third parties

The only outside parties this service actually talks to are Google and Apple (for sign-in), GitHub (for feedback), and Cloudflare (hosting the site and the sign-in server). No advertising, analytics, or tracking services.

This can change

If the app's behavior changes, this document changes with it. The date at the top marks the last edit.
