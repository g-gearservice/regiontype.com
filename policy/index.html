개인정보처리방침

2026년 10월 21일 시행

regiontype은 지명 타자연습입니다. 게임 자체는 로그인 없이 그대로 돌고, 아래 값들은 순위표에 이름을 올리기로 한 사람에게만 생깁니다.

안 받는 것

비밀번호와 전화번호를 받지 않습니다. Apple 로그인에는 메일·실명을 요청하지 않습니다. Google 로그인에서는 메일 주소(openid email 범위)를 요청하지만, 이 주소는 로그인 2단계 인증 코드를 보내는 데만 쓰고 계정에는 저장하지 않습니다. 광고나 방문자 분석 스크립트를 넣지 않고, 쿠키도 쓰지 않습니다. 계정 복구를 위해 직접 적는 보조 메일은 아래 절에 적었습니다.

로그인 (Google·Apple)

로그인은 Google 또는 Apple 계정으로 합니다. Google에는 openid email 범위를 요청하고, Apple에는 아무 범위도 요청하지 않습니다. Google에서 넘어온 메일 주소는 로그인할 때마다 일회용 코드를 보내는 데만 쓰며, 서버의 단기 로그인 요청 줄에만 머물다 로그인 완료 시 지워지고 계정에는 저장되지도 공개되지도 않습니다. 공급자가 주는 계정 식별 번호(sub)는 저희 서버 키로 한 번 더 섞어(HMAC) 저장하며, 원래 번호는 어디에도 남지 않습니다.

로그인 2단계 인증

로그인할 때마다 Google 계정 메일로 숫자 6자리 일회용 코드를 recover@regiontype.com에서 보내고, 그 코드를 입력해야 로그인이 끝납니다. 메일을 받을 수 없으면 복구 코드로 거칠 수 있습니다. 코드는 5분 동안 유효합니다. 한 번의 로그인 시도에 코드는 최대 5회까지 요청할 수 있고, 5회 틀리면 그 시도는 종료됩니다.

복구 코드

설정 › 보안에서 복구 코드를 받으면 일회용 복구 코드 8개를 한 번만 보여줍니다. 저장은 그 코드의 해시값만 하고, 코드 원문은 서버에 남지 않습니다. 코드를 쓰면 그 줄은 지워집니다.

보조 메일

계정 복구를 위해 선택적으로 보조 메일 주소를 직접 적을 수 있습니다(비밀번호 및 계정 복구 용도이나 regiontype에는 비밀번호가 없으므로 계정 복구에만 쓰입니다). 로그인 공급자에게 그 주소를 요청하지 않습니다. 확인된 주소에만 recover@regiontype.com이 평문으로 일회용 코드를 보냅니다. 그 코드와 확인 요청은 5분 동안만 유효합니다. 확인이 끝나면 주소 원문은 저장하지 않고 해시만 남깁니다. 계정 조회, 공개 프로필, 공개 이슈에는 주소를 싣지 않습니다. 확인되지 않은 주소에는 보내지 않으며, 화면의 안내 문구는 주소가 확인됐는지와 상관없이 같습니다.

메일을 묻기 전에, 무엇을 받는지, 왜 받는지(본인 확인과 계정 복구), 누가 보내는지, 일회용 코드와 확인 요청이 5분 동안만 유효한지, 그 주소가 공개 프로필과 공개 이슈에 보이지 않는지를 화면의 글로 먼저 알립니다.

로그인 세션

로그인 상태는 쿠키가 아니라 브라우저의 localStorage에 담긴 토큰으로 유지합니다. 이 토큰에는 임의로 만든 계정 번호와 만료 시각만 들어 있고, 90일 뒤 만료됩니다.

순위표

순위표에 이름을 올리면 코스·제한 시간·고른 이름·점수·정확도·시각이 공개로 걸립니다. 줄의 주인은 화면에 보이는 이름이 아니라 브라우저가 한 번 만든 난수라, 같은 이름을 다른 사람이 써도 서로의 기록에 손댈 수 없습니다. 결과 화면의 '내 기록 내리기'로 언제든 자기 줄을 지울 수 있습니다.

피드백

피드백은 GitHub 공개 이슈로 그대로 올라갑니다. 회신 주소는 받지 않습니다 — 입력칸 자체가 없습니다. 보낸 내용과 함께 종류, 앱 버전, 보고 있던 페이지 주소, 브라우저 정보가 같이 올라갑니다. 이 내용은 누구나 볼 수 있으니, 남길 내용에 개인 정보를 적지 마세요.

어디에 저장되나

순위표·계정 값은 Cloudflare D1(아시아·태평양 리전)에 저장합니다. 피드백은 GitHub 저장소의 공개 이슈로 저장합니다. 그 밖에 저희가 따로 두는 서버나 데이터베이스는 없습니다.

지우고 싶을 때

순위표 줄은 위에 적은 대로 스스로 지울 수 있습니다. 계정을 삭제하면 이중 인증 설정을 포함하여 계정과 연결된 모든 정보가 지워집니다.

제3자

이 서비스가 실제로 주고받는 곳은 로그인을 처리하는 Google·Apple, 피드백이 올라가는 GitHub, 사이트와 로그인 서버를 올려 두고 복구 메일을 recover@regiontype.com 에서 평문으로 보내는 Cloudflare, 그리고 홈 봇과의 대화를 받는 NVIDIA뿐입니다. 봇에게 친 글(최근 몇 마디)은 대답을 짓도록 NVIDIA의 AI 모델로 넘어가니, 개인정보는 적지 마세요. 로그인 정보는 함께 가지 않습니다. 그 밖의 광고·분석·추적 서비스는 쓰지 않습니다.

바뀔 수 있습니다

기능이 바뀌면 이 문서도 같이 고칩니다. 맨 위의 시행일로 마지막으로 고친 날을 알 수 있습니다.

Privacy Policy

Effective October 21, 2026

regiontype is a place-name typing drill. The game itself works without signing in. Everything below only applies once you choose to sign in and post to the leaderboard.

What we don't collect

No passwords and no phone numbers. We do not ask Apple for an email or a real name. For Google sign-in, we request the email scope (openid email) solely to send the sign-in one-time code, and the address is never stored in your account. No ads, no analytics scripts, no cookies. A secondary email you type yourself for recovery is described below.

Signing in (Google · Apple)

Sign-in goes through Google or Apple. We request the openid email scope from Google and no scope at all from Apple. The Google-verified email address is used ONLY to send a 5-minute one-time code at each sign-in; it is kept temporarily in the server's sign-in challenge row, deleted upon successful sign-in, and never stored in your account or displayed publicly. The provider's account id (its sub) is HMAC-hashed with a server-side key before storing, and the original id is never kept anywhere.

Two-step verification

Every sign-in sends a 6-digit one-time code from recover@regiontype.com to your Google account email, and sign-in finishes only once you enter it. If you can't receive that mail, a recovery code works instead. Codes are valid for 5 minutes. At most 5 codes can be requested per sign-in attempt, and 5 wrong tries end the attempt.

Recovery codes

Getting recovery codes in Settings › Security shows eight one-time codes, once. We store only their hash, never the codes themselves. Using a code deletes that entry.

Secondary email

You can optionally provide a secondary email address for Password & Account Recovery (account recovery; regiontype has no passwords). We do not ask the sign-in provider for that address. Only a confirmed address receives a one-time code, as plain text, from recover@regiontype.com. That code and its challenge last five minutes. After confirmation we do not store the address, only a hash. Account lookup, public profiles, and public issues do not include the address. An unconfirmed address is sent nothing, and the words on the screen are the same whether or not the address was confirmed.

Before asking for an email, the screen states in words what is collected, why (to verify who you are and to recover the account), who sends it, that the one-time code and its challenge last five minutes, and that the address is not shown on a public profile or a public issue.

Sessions

Sign-in state lives in a token in your browser's localStorage, not a cookie. The token holds nothing but a random account id and an expiry, and it expires after 90 days.

Leaderboard

Posting a score publishes the course, time limit, the name you chose, your score, accuracy, and a timestamp. Each row is owned by a random id the browser generates once, not by the display name, so two people can share a name without touching each other's rows. "Remove my score" on the result screen deletes your own rows at any time.

Feedback

Feedback is posted as-is to a public GitHub issue. We don't collect a reply address — there is no field for one. Your message goes up alongside its category, the app version, the page URL you were on, and your browser's user agent. Anyone can read this, so don't put personal information in what you send.

Where it's stored

Leaderboard and account data live in Cloudflare D1 (Asia-Pacific region). Feedback lives as public issues in our GitHub repository. We keep no other server or database.

Deleting things

You can remove your own leaderboard rows yourself, as above. Deleting your account erases all data associated with your account, including two-step verification settings.

Third parties

The outside parties this service talks to are Google and Apple (for sign-in), GitHub (for feedback), Cloudflare (hosting the site and sign-in server, and sending recovery mail from recover@regiontype.com), and NVIDIA (for chatting with the home bot). What you type to the bot (the last few lines) is sent to an NVIDIA AI model to write the reply, so please don't type personal details; your sign-in is not sent with it. No advertising, analytics, or tracking services.

This can change

If the app's behavior changes, this document changes with it. The date at the top marks the last edit.
